# Shaik Farzana Portfolio

A responsive single-page portfolio built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser.

## Customize before submission
- Replace the `#` project links in `index.html` with your actual GitHub/Live links.
- Add your LinkedIn URL if you want it shown.
- `resume.pdf` is included for the Download Resume button.

Animations included:
- Scroll reveal animations
- Floating hero code card
- Hover lift effects
- Cursor glow
- Mobile navigation
- Smooth scrolling
